### 2. Canonical `credits_to_bucket` (`src/pricing/economy.py`)

Pure function `credits_to_bucket(credits: int) -> str`. Boundary table verified by parametric tests:

| Credits | Bucket |
|---|---|
| `>= 20_000` | `"full"` |
| `19_999 .. 10_000` | `"semi-buy"` |
| `9_999 .. 5_000` | `"semi-eco"` |
| `4_999 .. 0` | `"eco"` |
| `< 0` | `"eco"` (defensive) |

Boundary verification at runtime:
- `20000 -> full`, `19999 -> semi-buy`, `10000 -> semi-buy`
- `9999 -> semi-eco`, `5000 -> semi-eco`, `4999 -> eco`, `0 -> eco`

This is the **single** implementation (CRule 2). Plan 02-03 (ETL) and Phase 3 (MatchState) both import it.
